# MetroHub - Train & Metro Ticket Booking

A responsive web application for booking intercity train and daily metro tickets, featuring dynamic pricing calculations, interactive booking modals, simulated e-ticket downloads, and a mobile-friendly interface[cite: 9, 10, 11].

## Features

* **Dual Booking Systems:** Dedicated booking form workflows and price estimation logic for both long-distance trains and local metro routes[cite: 9, 10, 11].
* **Interactive Modals & E-Tickets:** Instant booking confirmation popups with dynamically generated ticket IDs and downloadable text-format e-tickets[cite: 10, 11].
* **Responsive Navigation & UI:** Mobile-responsive layout equipped with a hamburger menu toggle, smooth scrolling anchor links, and FontAwesome icons[cite: 9, 10, 11].

## Technologies Used

* **HTML5**[cite: 9]
* **CSS3 (Flexbox & CSS Grid)**[cite: 11]
* **JavaScript (DOM Manipulation & Event Handling)**[cite: 10]
* **FontAwesome & Google Fonts (Poppins)**[cite: 9]
